# Kharon Hermes

> [!WARNING]
> ## Archived
> This Kharon/Hermes collector is no longer maintained and will receive no
> further releases. Both parent projects are retired as part of the Olympus
> PHP 7/Zend stack. Preserve it only for existing deployments.

This module provides a [Kharon](https://github.com/mt-olympus/kharon) collector for [Hermes](https://github.com/mt-olympus/hermes)
that automatically captures the requests and prepare a payload to a zeus server.
